# Tessellane Signal
Turns support tickets, call transcripts and usage events into ranked customer needs.
- Integrations: helpdesks, CRM notes, call recorders, product analytics (via webhooks and a REST API).
- Core objects: **Sources → Mentions → Themes → Opportunities**.
- API: REST with signed webhooks (public docs), rate limit 600 requests/min per workspace.
